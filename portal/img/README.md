# Imágenes del portal

## Foto del banner (encabezado)

Coloca aquí tu foto operando con el nombre **`portada.jpg`**:

    portal/img/portada.jpg

- Recomendado: **horizontal** (apaisada), buena resolución (ancho ≥ 1600 px).
- El portal la muestra a todo el ancho, **difuminada a los lados** y fundida
  con el fondo oscuro. El texto "UroWorkNet · by Dr. Juan Carlos Riera" va encima.
- Si no existe este archivo, el banner muestra un degradado elegante de respaldo
  (el sitio no se rompe).

Para cambiar el encuadre vertical, ajusta `background-position` de `.banner__img`
en `portal/index.html` (por defecto `center 30%`).
